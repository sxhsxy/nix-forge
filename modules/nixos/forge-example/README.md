# forge-example

示例模块，用于演示 nix-forge 的模块组织规范（四件套）。实现一个纯配置型
「服务」：启用后向 `/etc/forge-example.conf` 写入问候语，不安装任何软件包，
便于离线演示与测试。

## 选项

| 选项 | 类型 | 默认值 | 说明 |
| ---- | ---- | ------ | ---- |
| `services.forgeExample.enable` | bool | `false` | 启用本模块 |
| `services.forgeExample.message` | str | `Hello from nix-forge!` | 写入配置文件正文的问候语 |

## 使用

```nix
# flake.nix —— 消费方
{
  inputs.nix-forge.url = "github:sxhsxy/nix-forge";
  outputs = { nixpkgs, nix-forge, ... }: {
    nixosConfigurations.myHost = nixpkgs.lib.nixosSystem {
      modules = [
        nix-forge.nixosModules.forge-example   # 只引这一个
        # 或 nix-forge.nixosModules.default   # 全部模块
      ];
    };
  };
}
```

```nix
# configuration.nix —— 主机配置
{ ... }:
{
  services.forgeExample = {
    enable = true;
    message = "Hello, NixOS!";
  };
}
```

## 验证

```bash
nix flake check   # 冒烟检查：本模块可被求值
```

启用后 `/etc/forge-example.conf` 内容：

```
# generated by nix-forge (modules/nixos/forge-example)
message = Hello from nix-forge!
```
